# 🐍 Controlador-Roboldo — Algoritmo de Controlador em Python

Repositório oficial do algoritmo de controlador cinemático e interface de atuação em **Python (Pygame / PySerial / Bluetooth)** do **Roboldo** (**LAR / UERN**).

---

## 🎯 Escopo Técnico

- Controle de juntas e cinemática dos braços/cabeça do Roboldo em Python.
- Gerenciamento de conexão Serial e Bluetooth (`BluetoothSerialManager`) com os microcontroladores embarcados ([`Roboldo-IoT-Firmware`](https://github.com/ROBOLDO-UERN/Roboldo-IoT-Firmware)).
- Integração com o controlador geral ([`Roboldo-Orbit`](https://github.com/ROBOLDO-UERN/Roboldo-Orbit)).
